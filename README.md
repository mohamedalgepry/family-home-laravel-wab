# منصة فاميلي هوم العقارية — Family Home Platform

نظام إدارة وتسويق عقاري متكامل مبني باستخدام إطار العمل Laravel 13، يتبع المعمارية الموجهة بالمجالات (Domain-Driven Design — DDD)، ومدمج مع واجهة React 19 عبر Inertia.js v3. تم تصميم المنصة لتوفير أداء عالٍ على البيئات المحدودة (Shared Hosting) مع تقديم تجربة مستخدم كاملة الدعم ثنائي الاتجاه (RTL/LTR).

## المواصفات التقنية والمعمارية

- **الإطار الخلفي (Backend)**: Laravel 13 (PHP 8.3+)
- **معمارية النظام**: Domain-Driven Design (DDD) مع إتباع نمط Single Responsibility و Action Classes للعمليات المعقدة.
- **الواجهة الأمامية (Frontend)**: React 19 متصلة عبر Inertia.js v3 (Single Page Application دون الحاجة لتشغيلNode.js Server في البيئة الإنتاجية).
- **التصميم والأنماط (Styling)**: Tailwind CSS v4 مع نظام توكينز محدد (Design Tokens) ودعم كامل للاتجاهين (RTL/LTR) عبر ملفات اللغة (`lang/ar`, `lang/en`).
- **قواعد البيانات**: MySQL 8.0+ مع تحسين الاستعلامات عبر إضافة الفهارس (Indexes) و القيود الأجنبية (Foreign Keys) مسبقاً.
- **إدارة الطوابير والتخزين المؤقت**: `database` queue driver و `file` cache store لتقليل استهلاك الموارد وملاءمة بيئات الاستضافة المشتركة دون الاعتماد على Redis.

## المميزات الأساسية للنظام

1. **إدارة الكيانات العقارية (Projects & Units)**:
   - إدارة دقيقة للمشاريع والوحدات العقارية.
   - دعم مرن لخيارات الدفع (كاش، تقسيط، أو كلاهما) مع حقول الدفعة الأولى وعدد سنوات التقسيط ونوع التشطيب والخدمات والميزات.
   - توليد المعرفات الفريدة (Slugs) تلقائياً لتوافق محركات البحث (SEO).

2. **نظام النقاط والتثبيت (Priority Points System)**:
   - تخصيص نقاط أولوية للوحدات لرفع ترتيبها في نتائج البحث.
   - نظام خصم يومي تلقائي للطلبات غير المثبتة عبر Cron Job.
   - نظام إعادة التعيين الشهري لرصيد المديرين.
   - حماية جميع عمليات النقاط باستخدام المعاملات المباشرة لبيانات الدفع (`DB::transaction`).

3. **لوحة التحكم الإدارية المخصصة (Custom React/Inertia Admin Panel)**:
   - لوحة تحكم مخصصة بالكامل بدون الاعتماد على كتل جاهزة، توفر إدارة الأدوار (Admin / Manager / Agent).
   - إدارة المستخدمين والرسائل والمقارلات والاخبار والإعدادات والمناطق وأنواع الوحدات.

4. **إدارة الإعدادات والبروفايل الشخصي (Settings & Profile Management)**:
   - فصل بطاقات بيانات التواصل عن شبكات التواصل الاجتماعي.
   - دعم التثبيت المباشر لروابط الواتساب التفاعلية (`wa.me`) وحسابات LinkedIn وFacebook وInstagram وTwitter.
   - إمكانية تغيير كلمة السر وإدارة الحساب الشخصي من لوحة التحكم بمرونة وأمان كامل.

5. **معالجة الصور والوسائط (Asynchronous Image Processing)**:
   - رفع الصور وإرسال الاستجابة فورا للعميل، مع جدولة توليد المصغرات متعددة الأحجام في الخلفية عبر `GenerateThumbnailsJob`.

## البنية الهيكلية للمشروع (Domain Structure)

تم تنظيم المنصة وفق المعمارية الموجهة بالمجالات داخل مجلد `app/Domain`:

```text
app/
├── Domain/
│   ├── Listings/       # النماذج والخدمات الخاصة بالمشاريع والوحدات والمناطق
│   │   ├── Actions/
│   │   ├── DTOs/
│   │   ├── Models/
│   │   ├── Policies/
│   │   └── Services/
│   ├── Points/         # الخدمات والوظائف المجدولة لنظام النقاط والخصم اليومي
│   │   ├── Jobs/
│   │   ├── Models/
│   │   └── Services/
│   ├── Users/          # إدارة المستخدمين والمدراء والأدوار والرسائل
│   │   ├── Models/
│   │   ├── Policies/
│   │   └── Services/
│   └── Media/          # معالجة وتوليد مصغرات الصور في الخلفية
│       └── Jobs/
├── Http/
│   ├── Controllers/    # المتحكمات (مسؤولة عن الاستجابة فقط ولا تحتوي منطق أعمال)
│   └── Requests/       # FormRequests للتحقق من المدخلات
resources/
└── js/
    ├── Pages/          # صفحات React (Public & Admin)
    └── Components/     # مكونات الواجهة المسمّاة والمستقلة
```

## متطلبات البيئة والتثبيت المحلي

### المتطلبات الأساسية
- PHP >= 8.3
- Composer >= 2.5
- Node.js >= 20.0 & NPM >= 10.0
- MySQL Server >= 8.0

### خطوات الإعداد والتشغيل المحلي

1. **استنساخ المستودع وتثبيت المكتبات**:
   ```bash
   composer install
   npm install
   ```

2. **تجهيز بيئة العمل**:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

3. **إعداد قاعدة البيانات والتخزين**:
   ```bash
   php artisan migrate --seed
   php artisan storage:link
   ```

4. **تشغيل الخادم المحلي وأصول التطوير**:
   ```bash
   npm run dev
   php artisan serve
   ```

## إعدادات الإنتاج والرفع على الاستضافة المشتركة

### طريقة الرفع على Hostinger

لضمان عمل المشروع بأعلى كفاءة وبشكل آمن على استضافة Hostinger، يجب اتباع الخطوات التالية لضبط مجلد الجذر (Document Root) بدلاً من الطريقة القديمة لتعديل `index.php`:

1. قم برفع جميع ملفات المشروع إلى مدير الملفات (File Manager) في مجلد موقعك (مثلاً: `public_html/family-home`).
2. افتح لوحة تحكم hPanel الخاصة بـ Hostinger.
3. من القائمة الجانبية، اذهب إلى قسم المتقدم (Advanced) ثم اختر موقع الويب (Website).
4. ابحث عن خيار **مجلد الجذر (Document Root)**.
5. قم بتغيير مسار مجلد الجذر ليصبح `public_html/family-home/public` بدلاً من `public_html/family-home` (تأكد من مطابقة اسم المجلد الفعلي الذي رفعت عليه المشروع).
6. احفظ التغييرات. الآن سيوجه الخادم جميع الطلبات مباشرة إلى مجلد `public` حيث توجد حماية Laravel الافتراضية.

*(ملاحظة اختيارية)*: في حال كانت باقة الاستضافة الخاصة بك لا تدعم ميزة تغيير Document Root، فقد تم توفير ملف `index.php` كبديل احتياطي في جذر المشروع لتوجيه الطلبات إلى مجلد `public`. ومع ذلك، يُنصح بشدة بتغيير Document Root إن أمكن لضمان أفضل حماية وأداء.

تستوفي المنصة جميع المعايير اللازمة للتشغيل المستقر على خوادم الاستضافة المشتركة:

1. **بناء أصول الواجهة محلياً**:
   ```bash
   npm run build
   ```
   *(يتم تتبع مجلد `public/build` لضمان عمل الواجهة مباشرة دون الحاجة لأوامر بناء على السيرفر)*.

2. **ضبط ملف البيئة الانتاجية (`.env`)**:
   ```env
   APP_ENV=production
   APP_DEBUG=false
   CACHE_STORE=file
   QUEUE_CONNECTION=database
   SESSION_DRIVER=database
   INERTIA_SSR_ENABLED=false
   ```

3. **إعداد المهمة المجدولة (Cron Job)**:
   يجب إضافة أمر Cron واحد في لوحة تحكم الخادم ليعمل كل دقيقة:
   ```bash
   * * * * * cd /path-to-your-project && php artisan schedule:run >> /dev/null 2>&1
   ```
   يتكفل هذا الأمر بجميع مهام الطوابير، الخصم اليومي، وإلغاء التثبيت والتحديث الشهري.
