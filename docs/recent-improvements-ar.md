# سجل التحسينات الأخيرة

**تاريخ التحديث:** 13 نوفمبر 2026
**النطاق:** التحسينات المنفذة على الفرز والبحث، واجهة المساعد، إشعارات الإدارة، وبناء صفحات prerender.

## 1. البحث وفرز الوحدات

- أضيف فرز الوحدات حسب الأحدث، السعر تصاعديًا، السعر تنازليًا، والمساحة الأكبر، مع إبقاء ترتيب المميز كخيار افتراضي.
- يعتمد الخادم على قائمة قيم فرز مسموح بها، ولا يقبل اسم عمود مباشر من الطلب.
- أضيف ترتيب ثانوي ثابت عند تساوي القيم، وتحافظ عمليات الفرز والبحث على بقية الفلاتر.
- حُسن حوار فلاتر الهاتف بلوحة المفاتيح وإدارة التركيز وتسميات قارئ الشاشة.

التفاصيل وحالة التوصيات في [تقرير متابعة الإصلاحات](../review-plans/13-follow-up-fix-status.md).

## 2. واجهة المساعد وشريط المقارنة

- أصبح زر فتح المساعد يعرض اسمه ووصفه بدل الاعتماد على أيقونة منفردة، وخُففت الظلال والتباينات في الرسائل والردود السريعة.
- عند وجود وحدات أو مشاريع في المقارنة، يرتفع زر المساعد ونافذته على الهاتف إلى موضع يترك مساحة لشريط المقارنة. يعود إلى موضعه المعتاد عند إفراغ المقارنة؛ وتبقى إزاحة سطح المكتب كما هي.
- قُيد ارتفاع نافذة المحادثة على الهاتف لتظل قابلة للاستخدام ولا تتجاوز المساحة المتاحة فوق الشريط.

**التحقق البصري:** على صفحة الوحدات بعرض 390×844 بكسل، انتهى زر المساعد عند y=744 وبدأ شريط المقارنة عند y≈766، بفاصل يقارب 22 بكسل. اختُبر كذلك موضع نافذة المحادثة المفتوحة.

## 3. توجيه الإشعارات والصلاحيات

- رسائل الاستفسار عن إعلان تُرسل إلى مالك الإعلان ومديره، بينما يستطيع المسؤول رؤيتها في صندوق الرسائل دون تلقي إشعار خاص. استفسارات التواصل العامة تستمر في الوصول للمسؤول.
- إشعارات عملاء المساعد تُرسل للمسؤولين النشطين فقط، وتُخفى الإشعارات القديمة عن غير المسؤولين في القوائم والعدادات والإجراءات.
- تُحسب أزرار الإجراءات وروابطها على الخادم وفق صلاحيات المستخدم وحالة الوحدة أو المشروع، ثم تستخدم الواجهة هذه البيانات.
- عداد رسائل المسؤول يحصي الرسائل المسندة إليه؛ ولا يمنع ذلك المسؤول من رؤية الرسائل الأخرى في صندوق الإدارة.
- أخطاء تحميل الإشعارات والعدادات تظهر للمستخدم بدل تحويل الفشل إلى نتائج فارغة، و«مسح الكل» يقتصر على إشعارات المستخدم المرئية.
- تغير نطاق مفاتيح الكاش لمنع عرض بيانات مخزنة قبل تطبيق تصفية الوصول.

## 4. موثوقية أصول prerender

عُدلت أداة تحديث هاشات الأصول لتتعرف على مقاطع الهاش ذات الأحرف الكبيرة فقط. يمنع ذلك بقاء روابط CSS القديمة في ملفات HTML الثابتة، ويتيح لـ `DetectBot` تقديم الصفحات بعد التحقق من توافق الأصول مع manifest الحالي.

## 5. التحقق

| الفحص | النتيجة |
|---|---|
| `php artisan test` | نجح: 355 اختبارًا، 2010 تأكيدات |
| اختبارات الرسائل والإشعارات المستهدفة | نجحت: 26 اختبارًا، 112 تأكيدًا |
| `npm run lint` | نجح دون تحذيرات |
| `npm run build` | نجح، وتم التحقق من 36 صفحة prerender دون روابط localhost أو أصول قديمة |
| اختبار موضع المساعد في المتصفح | نجح على الهاتف مع وجود المقارنة ومع فتح المحادثة |
| `git diff --check` | نجح |

هذه التحسينات لا تعني إغلاق كل نتائج التدقيق السابق؛ ما زالت قياسات Lighthouse ومراجعة Accessibility الشاملة واختبارات staging بحاجة إلى تنفيذ مستقل. راجع [التقرير المجمع](../review-plans/SITE_REVIEW_MASTER_REPORT.md) و[حالة المتابعة](../review-plans/13-follow-up-fix-status.md).
