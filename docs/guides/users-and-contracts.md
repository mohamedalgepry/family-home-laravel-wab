# دليل إدارة المستخدمين والرسائل

## إدارة المستخدمين

### الوصول
**القائمة الجانبية → المستخدمون** — متاح لـ `admin` فقط.

### الأدوار

| الدور | الرمز | الوصول |
|---|---|---|
| مدير النظام | `admin` | وصول كامل بلا قيود |
| مدير | `manager` | وحدات، مشاريع، نقاط، محتوى |
| وكيل | `agent` | وحداته الخاصة فقط |

### إضافة مستخدم جديد

من صفحة المستخدمين → **إضافة مستخدم**:
- الاسم الكامل
- البريد الإلكتروني (فريد)
- كلمة المرور
- الدور (admin / manager / agent)
- رقم الهاتف (اختياري)
- رقم الواتساب (اختياري — يُستخدم في كروت الوحدات)

> **هام**: رقم الواتساب الخاص بالمستخدم يظهر تلقائياً في كروت الوحدات التي يرفعها.
> إذا لم يُسجَّل رقم، يُستخدم رقم الشركة من الإعدادات.

### تعديل المستخدم

- يمكن تعديل بيانات أي مستخدم من قائمة المستخدمين.
- لتغيير كلمة المرور: اترك حقل كلمة المرور فارغاً للإبقاء على الكلمة الحالية.

## إدارة الرسائل

### الوصول
**القائمة الجانبية → الرسائل**

الأدوار: `admin`، `manager`، `agent` (يرى رسائله فقط).

### سير العمل

1. يرسل الزائر رسالة من صفحة **تواصل معنا** أو كرت العقار.
2. تظهر الرسالة في صندوق الوارد بلوحة التحكم.
3. يستطيع المسؤول الرد من داخل اللوحة أو عبر الواتساب مباشرةً.

### حالات الرسائل

| الحالة | الوصف |
|---|---|
| جديدة | لم تُقرأ بعد |
| مقروءة | تم الاطلاع عليها |
| تمت المعالجة | تم الرد أو الإغلاق |

## الأمان وصلاحيات الوصول

### حماية Admin Routes

- جميع مسارات `/admin/*` محمية بـ `EnsureUserHasRole` middleware.
- محاولة الوصول المباشر لمسار محظور → إعادة التوجيه إلى `/admin` مع رسالة خطأ.
