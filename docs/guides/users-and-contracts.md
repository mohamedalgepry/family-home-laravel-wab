# دليل إدارة المستخدمين والرسائل

## إدارة المستخدمين

### الوصول
**القائمة الجانبية → المستخدمون** — متاح لـ `admin` فقط.

### الأدوار

| الدور | الرمز | الوصول |
|---|---|---|
| مدير النظام | `admin` | وصول كامل بلا قيود |
| مدير | `manager` | وحدات، مشاريع، نقاط، محتوى |
| وكيل | `agent` | وحداته الخاصة فقط |

### إضافة مستخدم جديد

من صفحة المستخدمين → **إضافة مستخدم**:
- الاسم الكامل
- البريد الإلكتروني (فريد)
- كلمة المرور
- الدور (admin / manager / agent)
- رقم الهاتف (اختياري)
- رقم الواتساب (اختياري — يُستخدم في كروت الوحدات)

> **هام**: رقم الواتساب الخاص بالمستخدم يظهر تلقائياً في كروت الوحدات التي يرفعها.
> إذا لم يُسجَّل رقم، يُستخدم رقم الشركة من الإعدادات.

### إجراءات إدارة المستخدمين في اللوحة

تتميز صفحة المستخدمين بتصميم متجاوب بالكامل (Desktop Table + Mobile Cards):
- **تغيير الدور (`Change Role`)**: متاح لـ `admin` لتعديل رتبة المستخدم مع ربطه بمدير مباشر عند اختياره كـ `agent` (محمي ضد التغيير الذاتي لحساب الأدمن).
- **تغيير كلمة السر (`Change Password`)**: تغيير فوري لكلمة سر أي مستخدم مع اشتراط تعقيد كلمة السر (8 خانات على الأقل مع أحرف وأرقام).
- **نقل المشاريع (`Transfer Projects`)**: نقل ملكية مشاريع ووحدات مستخدم لآخر قبل الحذف أو عند إعادة توزيع الفرق.
- **تفعيل / تعطيل الحساب (`Toggle Active`)**: زر تفاعلي فوري لتبديل حالة الحساب (محمي لمنع الأدمن من تعطيل حسابه الحالي بالخطأ).
- **تعيين الوكلاء للمدير (`Assign Agents`)**: نافذة منبثقة سريعة لتوزيع وتعيين الوكلاء تحت إشراف مدير محدد.
- **حذف المستخدم (`Delete User`)**: فحص العلاقات قبل الحذف وتوفير خيار نقل البيانات التابعة لحساب آخر لحماية سلامة البيانات.

### ضوابط الأمان لحساب الأدمن (Self-Protection Safeguards)
1. لا يمكن للأدمن تغيير دور حسابه الخاص.
2. لا يمكن للأدمن حذف حسابه الخاص.
3. لا يمكن للأدمن تعطيل حسابه الخاص منعاً لفقدان الوصول للنظام.

## إدارة الرسائل

### الوصول
**القائمة الجانبية → الرسائل**

الأدوار: `admin`، `manager`، `agent` (يرى رسائله فقط).

### سير العمل

1. يرسل الزائر رسالة من صفحة **تواصل معنا** أو كرت العقار.
2. تظهر الرسالة في صندوق الوارد بلوحة التحكم.
3. يستطيع المسؤول الرد من داخل اللوحة أو عبر الواتساب مباشرةً.

### حالات الرسائل

| الحالة | الوصف |
|---|---|
| جديدة | لم تُقرأ بعد |
| مقروءة | تم الاطلاع عليها |
| تمت المعالجة | تم الرد أو الإغلاق |

## الأمان وصلاحيات الوصول

### حماية Admin Routes

- جميع مسارات `/admin/*` محمية بـ `EnsureUserHasRole` middleware.
- محاولة الوصول المباشر لمسار محظور → إعادة التوجيه إلى `/admin` مع رسالة خطأ.
