# دليل إضافة وإدارة المشاريع العقارية

## الوصول

من لوحة التحكم: **القائمة الجانبية → المشاريع → إضافة مشروع جديد**

الأدوار المسموح لها: `admin`، `manager`

---

## خطوات إضافة مشروع جديد

يعتمد النموذج على 4 خطوات (Multi-Step Form):

### الخطوة 1: البيانات الأساسية (Basic Info)

| الحقل | ملاحظات |
|---|---|
| الاسم بالعربية | مطلوب |
| الاسم بالإنجليزية | مطلوب |
| المنطقة | من قائمة المناطق |
| طريقة الدفع | كاش / تقسيط / كلاهما |
| الدفعة الأولى | عند اختيار التقسيط |
| عدد سنوات التقسيط | عند اختيار التقسيط |
| رابط الفيديو | YouTube أو Vimeo |
| الوصف بالعربية | تفاصيل المشروع |
| الوصف بالإنجليزية | تفاصيل المشروع |
| الميزات | اختيار متعدد |
| نوع التشطيب | من القائمة |
| المدير المسؤول | `admin` فقط يستطيع تعيين مدير |

### الخطوة 2: الوسائط (Media)

- صور المشروع بالترتيب (Drag & Drop).
- حد أقصى 10MB للصورة، 40MB للمجموعة.

### الخطوة 3: SEO

| الحقل | ملاحظات |
|---|---|
| العنوان (عربي/إنجليزي) | meta title |
| الوصف (عربي/إنجليزي) | meta description |
| الكلمات المفتاحية | مفصولة بفاصلة |

### الخطوة 4: الموقع (Location)

| الحقل | ملاحظات |
|---|---|
| العنوان التفصيلي (عربي/إنجليزي) | نص حر |
| رابط الخريطة المضمنة | Google Maps embed URL |

---

## حماية التقديم المزدوج

زر الحفظ يُعطَّل أثناء معالجة الطلب لمنع الإرسال المتكرر.

---

## ملاحظات

- بعد إنشاء المشروع، يمكن إضافة وحدات مرتبطة به من صفحة الوحدات.
- يظهر Slug الـ URL تلقائياً بناءً على الاسم الإنجليزي.
- يمكن تعديل ترتيب الصور بالسحب والإفلات.
