# دليل إضافة وإدارة الوحدات العقارية

## الوصول

من لوحة التحكم: **القائمة الجانبية → الوحدات → إضافة وحدة جديدة**

الأدوار المسموح لها: `admin`، `manager`، `agent`

---

## خطوات إضافة وحدة جديدة

يعتمد النموذج على 4 خطوات (Multi-Step Form):

### الخطوة 1: البيانات الأساسية (Basic Info)

| الحقل | نوع البيانات | ملاحظات |
|---|---|---|
| الاسم بالعربية | نص | مطلوب |
| الاسم بالإنجليزية | نص | مطلوب |
| السعر | رقم | بالجنيه المصري |
| طريقة الدفع | اختيار | كاش / تقسيط / كلاهما |
| الدفعة الأولى | رقم | يظهر عند اختيار التقسيط |
| عدد سنوات التقسيط | رقم | يظهر عند اختيار التقسيط |
| المنطقة | اختيار | من قائمة المناطق |
| نوع الوحدة | اختيار | من قائمة أنواع الوحدات |
| نوع التشطيب | اختيار | من قائمة أنواع التشطيب |
| المساحة | رقم | بالمتر المربع |
| عدد الغرف | رقم | اختياري |
| عدد الحمامات | رقم | اختياري |
| نوع الإعلان | اختيار | للبيع / للإيجار |
| الوصف بالعربية | نص طويل | اختياري |
| الوصف بالإنجليزية | نص طويل | اختياري |
| الميزات | اختيار متعدد | من قائمة الميزات |

### الخطوة 2: الوسائط (Media)

- **الصورة الرئيسية**: صورة واحدة تمثل الوحدة (max 10MB).
- **صور إضافية**: يمكن رفع أكثر من صورة (max 40MB إجمالي).
- عند الرفع يبدأ توليد Thumbnails في الخلفية تلقائياً.

### الخطوة 3: SEO

| الحقل | ملاحظات |
|---|---|
| العنوان بالعربية | للـ meta title |
| العنوان بالإنجليزية | للـ meta title |
| الوصف بالعربية | للـ meta description |
| الوصف بالإنجليزية | للـ meta description |
| الكلمات المفتاحية (عربي) | مفصولة بفاصلة |
| الكلمات المفتاحية (إنجليزي) | مفصولة بفاصلة |

### الخطوة 4: الموقع (Location)

| الحقل | ملاحظات |
|---|---|
| العنوان بالعربية | نص |
| العنوان بالإنجليزية | نص |
| رابط الخريطة المضمنة | رابط Google Maps embed |

---

## حماية التقديم المزدوج

زر الحفظ يُعطَّل تلقائياً أثناء معالجة الطلب.
في حال الضغط مرتين قبل الاستجابة، لا يُرسَل إلا طلب واحد.

---

## نقاط الأولوية (Priority Points)

بعد إنشاء الوحدة، يمكن لـ `admin` أو `manager` رفع أولويتها عبر:
**قائمة الوحدات → أيقونة النقاط** ← تخصيص عدد النقاط.

- كلما زادت النقاط، ظهرت الوحدة في مقدمة نتائج البحث والصفحة الرئيسية.
- تُخصم نقطة يومياً تلقائياً إذا لم تكن الوحدة مثبتة.

---

## واتساب التواصل

كرت الوحدة يعرض رقم واتساب رافع الإعلان.
إذا لم يكن لديه رقم، يُستخدم رقم الشركة من إعدادات الموقع تلقائياً.
