# دليل إدارة نظام النقاط والخصومات

## نظرة عامة

نظام النقاط يتيح رفع ترتيب الوحدات العقارية في نتائج البحث والصفحة الرئيسية.
كلما زادت نقاط الوحدة، ظهرت في مقدمة القائمة.

---

## الأدوار والصلاحيات

| العملية | admin | manager | agent |
|---|---|---|---|
| تخصيص نقاط لوحدة | ✓ | ✓ | ✗ |
| تثبيت وحدة (Pinning) | ✓ | ✓ | ✗ |
| عرض رصيد النقاط | ✓ | ✓ | ✗ |
| إعادة تعيين الرصيد الشهري | ✓ | ✗ | ✗ |

---

## آلية عمل النظام

### تخصيص النقاط

1. افتح **قائمة الوحدات**.
2. اضغط على أيقونة **النقاط** بجانب الوحدة المطلوبة.
3. حدد عدد النقاط المراد تخصيصها.
4. اضغط **حفظ** — تُخصم النقاط من رصيد المدير فوراً.

### الخصم اليومي التلقائي

- تُشغَّل مهمة `DailyPointDeductionJob` كل يوم تلقائياً عبر Cron Job.
- كل وحدة غير مثبتة تفقد نقطة واحدة يومياً.
- إذا وصل الرصيد إلى صفر، تُزال الوحدة من قائمة المميزات.

### التثبيت (Pinning)

- تثبيت الوحدة يضمن ظهورها دائماً في المقدمة دون خسارة النقاط.
- التثبيت يتطلب رصيداً كافياً من النقاط.

### إعادة التعيين الشهري

- في أول كل شهر، يُعاد تعيين رصيد النقاط للمديرين تلقائياً.
- يُنفَّذ ذلك عبر مهمة مجدولة في `app/Console/Kernel.php`.

---

## الحماية والأمان

- جميع عمليات النقاط محمية بـ `DB::transaction` لضمان الاتساق.
- الوكلاء (Agents) ممنوعون من تعديل نقاط أي وحدة بواسطة Policy خاصة.
- محاولة الوصول المباشر من Agent لمسار النقاط → رفض 403.
