# دليل المكتبات والتقنيات المستخدمة — Family Home

يقدم هذا الدليل توثيقاً شاملاً باللغة العربية لأهم المكتبات وحزم البرمجيات المعتمدة في مشروع **Family Home**، مع توضيح وظيفة كل مكتبة، طريقة استخدامها، وأفضل الممارسات المتبعة في المشروع.

---

## 1. إطار العمل والواجهة الخلفية (Backend)

### Laravel 13 (PHP 8.3+)
- **الوصف:** إطار العمل الرئيسي للتطبيق، يعتمد معمارية الـ MVC مع تقسيم Domain-Driven Design (DDD) إلى مجالات مستقلة (Listings, Users, Points, Media).
- **الميزات المستخدمة في المشروع:**
  - **Eloquent ORM & Scopes:** لإدارة العلاقات والاستعلامات المتقدمة وفهارس البحث.
  - **Policies & Gates:** 12 سياسة وصول للتحكم بالأدوار والصلاحيات (Admin, Manager, Agent).
  - **Database Queues & Schedule:** معالجة المهام الثقيلة (كالخصم اليومي وضغط المصغرات) في الخلفية عبر جدول jobs.
  - **Notifications & Mail:** إرسال التنبيهات عبر قاعدة البيانات وقناة البريد الإلكتروني.

### Pest PHP v4
- **الوصف:** إطار اختبارات خفيف ومتقدم مبني فوق PHPUnit، يتميز بصيغة قراءة سلسة ومباشرة.
- **التشغيل:**
  `ash
  php artisan test
  `
- **الممارسات في المشروع:** تغطية سياسات التحكم بالوصول، منطق الخدمات في Domain Layer، والتحقق من صحة رؤوس الأمان والكاش.

---

## 2. الواجهة الأمامية والربط (Frontend & Fullstack)

### Inertia.js v3
- **الوصف:** طبقة الربط الحديثة بين Laravel و React لبناء تطبيق أحادي الصفحة (SPA) كلاسيكي بدون الحاجة لكتابة REST APIs منفصلة أو تعقيد إدارة التوثيق (JWT/CORS).
- **الميزات المستخدمة في المشروع:**
  - مشاركة البيانات التلقائية عبر HandleInertiaRequests.
  - التوجيه السريع بدون إعادة تحميل الصفحة الكاملة عبر مكون <Link />.
  - التعامل مع الأخطاء وإعادة التحميل التلقائي عبر حماية Hard Navigation Fallback.

### React 19
- **الوصف:** مكتبة بناء واجهات المستخدم التفاعلية من Meta.
- **الممارسات في المشروع:**
  - المكونات الوظيفية (Functional Components) مع الـ Hooks (useState, useEffect, useMemo, useCallback).
  - معالجة حالات اللمس السريع للهواتف الذكية وتخفيض زمن الاستجابة.

### Tailwind CSS v4
- **الوصف:** إطار تنسيق معتمد على الـ Utility-First CSS مع دعم مباشر للخصائص المنطقية ثنائية الاتجاه (RTL/LTR).
- **السمات الأساسية في المشروع:**
  - خط **Cairo** الموحد والمحلي لكامل الواجهة.
  - اللون الرئيسي السلطوي #CC0000 (Red) ولون الواتساب #16a34a.
  - زوايا التدوير: ounded-2xl للبطاقات، ounded-xl للأزرار وحقول الإدخال، وounded-full للشارات.

### Lucide React
- **الوصف:** مكتبة أيقونات SVG خفيفة ومتناسقة ومفتوحة المصدر.
- **الاستخدام:** أيقونات التنقل، أزرار التواصل، فلاتر البحث، وإحصائيات لوحة التحكم.

## 3. الوسائط والملفات

### Intervention Image
- **الوصف:** مكتبة متقدمة لمعالجة وتعديل الصور في PHP تدعم محركي GD و Imagick.
- **الاستخدام في المشروع:**
  - توليد مصغرات الهواتف خفيفة الحجم بصيغة WebP (بعرض 400px وبجودة محسنة).
  - التخفيض التلقائي لحجم الصور الأصلية الضخمة لضمان سرعة التحميل وتفادي استهلاك موارد الخادم المشترك.
